النطاق: شاشة «اكتشف» وغلاف التنقل المشترك، من دون تغيير ألوان الثيمات أو رموزها أو منطق اختيارها.

## الحكم النهائي

اكتمل إصلاح جميع مشكلات العرض الاستجابية التي كشفها التدقيق السابق. فلسفة نقل عنوان الفيلم وسنته إلى داخل البوستر تعمل الآن عبر المظاهر الثلاثة (`cinema` و`premiere` و`montage`)، وفي الوضعين الفاتح والداكن، وباتجاهي العربية RTL والإنجليزية LTR.

وضوح النص لا يعتمد على لون ثابت في صورة الفيلم نفسها. طبقة البيانات تستخدم حبرًا سينمائيًا فاتحًا فوق تدرج سفلي متعدد المراحل، مع ظل خفيف للنص، ويظل العنوان داخل سطرين والسنة تحته. بذلك بقي النص مقروءًا فوق الملصقات الفاتحة والمزدحمة والداكنة، مع الحفاظ على مساحة الملصق وتأثيره البصري.

## التحقق البصري الموسع

شُغلت نسخة إنتاج محلية للواجهة على API محلي حتمي، ثم فُحصت الصور الخام ولوحات المقارنة يدويًا. نُفذت المصفوفة التالية:

- العربية: 3 مظاهر × وضعين لونيين × 11 حجم عرض = 66 حالة.
- الإنجليزية: 3 مظاهر × وضعين لونيين × 3 أحجام عرض = 18 حالة.
- الإجمالي: 84 لقطة خام و14 لوحة مقارنة، أي 98 ملف دليل بصري.
- أحجام العربية: `360×740` و`390×844` و`430×932` و`768×1024` و`899×768` و`900×768` و`1024×768` و`1049×800` و`1050×800` و`1440×1000` و`1920×1080`.
- أحجام الإنجليزية: `360×740` و`1024×768` و`1920×1080`.

نجحت الحالات الـ84 في العقود الآتية:

- لا تجاوز أفقي (`overflowX = 0`).
- كل البطاقات بنسبة `0.667`، أي `2:3`.
- لا تداخل بين شريط التنقل والبوستر الأول أو عنوانه أو سنته أو زر الحفظ.
- لا تداخل بين العنوان وشارة المشاهدة أو زر الحفظ، ولا بين الشارة والزر.
- زر الحفظ `44×44` بكسل في جميع الحالات.
- العنوان أبيض، داخل البوستر، مقيد بسطرين، والتدرج السفلي حاضر في جميع البطاقات.
- جميع صور الكتالوج المطلوبة اكتملت، ولم تظهر أخطاء في وحدة تحكم المتصفح.
- اتجاه العربية RTL والإنجليزية LTR صحيحان، والعنوان الإنجليزي الطويل `Everything Everywhere All at Once` بقي ضمن سطرين.
- هوية كل مظهر بقيت محفوظة: نصف قطر البوستر 14 بكسل في `cinema`، و8 بكسل في `premiere`، و3 بكسل في `montage`.

الأدلة موجودة في:

- `output/playwright/theme-matrix-fix-2026-09-06/` — الصور الخام ولوحات المقارنة وسكربتات الالتقاط.
- `output/playwright/theme-matrix-2026-09-06/visual-report.md` — تقرير الحالة السابقة التي قادت إلى هذه الإصلاحات.

## الحماية من الرجوع

أضيف اختبار عقد استجابي في `apps/frontend/app/__tests__/ResponsiveLayoutContract.test.ts` يثبت:

- انتقال التنقل من الشريط السفلي إلى الرأس في الشاشات الواسعة والتابلت الأفقي.
- بقاء شبكة الهاتف بعمودين وعدم حل المشكلة بتصغير البوستر.
- قيم الضغط الرأسي التي تبقي بيانات أول بوستر واضحة على 360×740 وداخل طية 1440×1000.

نتائج التحقق بعد آخر تعديل:

- `npm run test -w apps/frontend`: نجح — 26 ملفًا و187 اختبارًا.
- `npm run lint -w apps/frontend`: نجح بلا ملاحظات.
- `API_PROXY_TARGET=http://127.0.0.1:3221 npm run build -w apps/frontend -- --webpack`: نجح بناء Next.js الإنتاجي مع فحص TypeScript وتوليد 16 صفحة.
- سجل المتصفح: صفر أخطاء، وطلبات التطبيق المرصودة أعادت `200 OK`. ظهرت ثلاثة تحذيرات غير حاجبة من المتصفح عن CSS preloaded لم يُستخدم خلال الثواني الأولى؛ لا تغيّر العرض ولم تكن ناتجة عن فشل طلب.

## حدود الدليل

هذا قبول بصري محلي لنسخة إنتاج مبنية من الشفرة الحالية، ببيانات API حتمية. لا يثبت نشرًا حيًا على بيئة الإنتاج، ولا يغطي جهازًا ماديًا أو لوحة مفاتيح هاتف مفتوحة. كما أنه لا يغيّر استراتيجية المظاهر أو ألوانها؛ الإصلاح مشترك في بنية العرض فقط، ولذلك يطبق الفلسفة نفسها على المظاهر الثلاثة بدل إنشاء استثناءات لكل ثيم.
