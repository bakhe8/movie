# خارطة الطريق إلى Beta

**التاريخ**: 2026-09-05  
**أساس القراءة**: commit `b87577f` على `main`  
**آخر تحقق حي**: Railway Production في 2026-09-05؛ نجح canary عند 11:36 و15:02 بتوقيت الرياض، واكتملت استعادة الحساب والدخول بعدها، وفُعّل Sentry في خدمتي الخلفية والنموذج  
**النوع**: `AR | execution roadmap | non-normative`  
**الحالة**: لوحة تنفيذ وتحقق؛ لا تعد إذناً بدعوة مستخدمين أو إطلاق Beta

هذه الوثيقة تجمع الطريق التنفيذي من الحالة الحالية إلى **Closed Beta** ثم **Public Arabic Beta**. لا تستبدل المخطط العربي المعياري ولا [SPECIFICATION.md](SPECIFICATION.md)، بل تقطر ما يلزم فعله الآن من [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)، [REMEDIATION_MAP_2026-09-05.md](REMEDIATION_MAP_2026-09-05.md)، [AUDIT_2026-09-05.md](AUDIT_2026-09-05.md)، [ALPHA_PLAN_2026-09-04.md](ALPHA_PLAN_2026-09-04.md)، و[WAVE1_AUDIT_AND_DECISION_2026-09-05.md](WAVE1_AUDIT_AND_DECISION_2026-09-05.md).

حالات البنود في هذه الوثيقة:

- **منجز**: موجود في الشيفرة ومغطى بدليل مناسب لنطاقه.
- **ينتظر إثباتاً حياً**: التنفيذ موجود، لكن تفعيل الإنتاج أو الرحلة الخارجية لم يُثبت بعد.
- **مسودة جاهزة**: المحتوى موجود، لكن يحتاج اعتماداً أو تجميد نسخة قبل الاستخدام.
- **متبقٍ فعلاً**: لا يوجد تنفيذ أو قرار يغلق البند بعد.
- **يعتمد على بيانات بشرية**: لا يغلقه اختبار آلي أو commit.

## 3. تعريف المراحل التنفيذية

نستخدم أسماء المراحل كما في المخطط: **Alpha**، **Closed Beta**، **Public Arabic Beta**. كلمة Wave هنا تعني دفعة بحث داخل Alpha، لا مرحلة منتج جديدة.

| المرحلة | التعريف العملي | مخرجها |
|---|---|---|
| Production Alpha Proof | إثبات أن النشر الحالي يسمح لمستخدم جديد بالوصول إلى توصية بلا تدخل. | canary ناجح أو جولتان يدويتان موثقتان على iPhone وAndroid. |
| Wave 1 Alpha Research | 15 مشاركاً مؤهلين، على 5 + 5 + 5، جلسات مدارة وصفر إنفاق. | قرار: استمر، أصلح ثم أعد، أو أوقف. |
| Alpha Cohort | توسيع منظم بعد Wave 1 إلى 80-150 مستخدماً أو حسب قدرة الدعم. | بيانات استخدام وقيمة كافية لقرار Closed Beta. |
| Closed Beta | دعوات أوسع لكن غير عامة، مع تشغيل مستقر وقياس موثوق ودعم. | retention أولي وتوصيات تتحول إلى مشاهدة/ترتيب لاحق بلا فجوة عربية كبيرة. |
| Public Arabic Beta | فتح عام عربي محدود مع readiness تشغيلي وقانوني وتسويقي. | نمو عضوي قبل paid spend. |

## 6. ما لا نعمله الآن

| الشيء | سبب التأجيل |
|---|---|
| paid acquisition | لا توجد بعد قيمة بشرية كافية ولا attribution موثوق. |
| creator outreach / مشاركة عامة | تحتاج صفحة قبل الحساب وmetadata عربية وخصوصية ودعم عام جاهزين. |
| availability provider | مفيد، لكنه ليس مانع Wave 1 ما دام التوفر يعلن `unknown`. |
| توسع خارج السعودية | السعودية سوق تعلم أول لتقليل المتغيرات، لا لإثبات حجم سوق. |
| monetization أو payments | قبل retention والقيمة، الدفع سيخلط القياس. |
| shared latent disclosure | مؤجل إلى بوابات `BP §17.3`، ولا يستخدم كرسالة في Wave 1. |

## 7. تعريف Done حسب الهدف

### Alpha Proof Done

- health حي.
- catalog >= 300.
- model service حي ومثبت داخل رحلة الإنتاج بالنموذج `plackett-luce-v3`.
- canary المجدول يصل إلى 5 توصيات؛ آخر تشغيلين ظاهرين نجحا بلا فشل.
- لا فشل صامت عند التدريب؛ canary ينتظر النتيجة ويفشل الرحلة عند تعذر الجاهزية.
- سجل الدليل مؤرخ في هذه الخارطة؛ معرّف النشر ولقطات الهاتف يكتملان ضمن G2 قبل Wave 1.

### Wave 1 Done

- 15 مشاركاً مؤهلاً بدأوا فعلياً.
- سجل بحث لكل مشارك.
- A0/V0/A1/A3 مفصولة.
- كل فشل مصنف بسبب.
- لا حادث خصوصية أو تشغيل.
- قرار مكتوب: استمر / أصلح وأعد / أوقف.

### Closed Beta Done

- cohort أكبر من Wave 1.
- توصيات تتحول إلى أفعال لاحقة بدرجة مفهومة.
- metrics لا تخلط click/watch/ranked_later.
- حقوق الخصوصية والدعم تعمل بلا ملاحظة يدوية مستمرة.
- لا Critical/High مفتوح بلا قبول مكتوب.

### Public Arabic Beta Done

- signup عام مستقر.
- load/security/cost monitoring مثبت.
- صفحة عامة ورسائل لا تعد بما لا يقيسه المنتج.
- قناة دعم عامة.

### بعد إغلاق Beta وقبل V1

- حقوق العرض والملصقات والإسناد مناسبة لمرحلة V1.
- قرار availability التجاري، إن وجد، موثق ومفصول عن Personal Fit.
- مراجعة قانونية/تشغيلية نهائية لأي توسع يتجاوز beta العامة.
