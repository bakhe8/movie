# L1 — أساس الفاتح، جاهز للمراجعة المستقلة

الأساس: `30048ff0f4667b451940ea80019880f25d35b9df`؛ المرجع وخريطة L0: `d984a9de668f3b4914e1cde39633b23be302b6f8`.
هذه حزمة بنية الثيم، وليست قبولًا بصريًا للشاشات أو اكتمال L2/L3.

| البند | النتيجة |
|---|---|
| أصل الصورة المختارة | محفوظ كما هو مع SHA-256 في README |
| رموز الفاتح | الأزرق للفعل، الليموني لموضع الترتيب/المسار النشط فقط؛ مستهلكوه في L2 |
| الداكن الموجود | كتلتا CSS الأصليتان متطابقتان بايتًا مع الأساس؛ لون الإقلاع الداكن محفوظ؛ الرموز الجديدة فقط تحيل إلى الأزرق/الغسلة الداكنة الموجودة |
| اختيار الثيم | اختبارات boot وprovider وtoggle: النظام الفاتح/الداكن، الاختيار الصريح، الاستعادة، تغير النظام، المزامنة بين التبويبات |
| التباين | النصوص ≥4.5:1 والأطر ≥3:1 على أرضيات الفاتح؛ النص على الليموني 14.45:1 |
| البناء والأنواع | `npm run build --workspace=frontend` ناجح، بما فيه TypeScript |
| الاختبارات | مجموعة الواجهة كاملة: 107 اختبارات ناجحة في 17 ملفًا؛ اختبارات L1 المركزة: 20 اختبارًا |

| لقطات المنتج قبل/بعد | لم تُنجز: المعاينة المقيدة لا تجد Next المثبت في جذر monorepo وتفرض أعلام Vite؛ لم نغيّر إعداد المنتج لتجاوز ذلك |

| الخطوة التالية | مراجعة L1 ودمجها وفق التنسيق، ثم L2؛ لا نشر إنتاج من هذه الحزمة |
